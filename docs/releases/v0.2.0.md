# DesignerBIM P01 v0.2.0 — 可编辑门实例

目标 Blender **5.2.2**。本版为测试候选，尚非施工图或生产 BIM 工具。扩展 ID `designer_bim_p01` 和固定更新源均不变。

## 新功能

- 新增门：位置、门洞宽高、左右铰链；自动唯一编号。
- 复制当前门：继承尺寸、开向与共享定义，但创建新实例 ID，不复制人工说明或审核状态。
- 精确定位：从墙左端输入绝对中心坐标，或输入相对沿墙位移。参数更新同源驱动墙洞、3D、平立面。
- 门高编辑：当前、选中或同定义范围；框截面不随高度拉伸。立面显示实际门洞高度。
- 左右铰链：3D 门扇与平面开启符号同向变化；原型三维统一90°开启，立面仍按关闭外形表达，非任意角度或通用投影模型。
- 增加 schema 1→2 迁移与旧 JSON 备份，保留旧说明的复核状态。未来数据版本明确拒绝。
- 侧栏操作分组、等高按钮与多行实例选择；修正旧面板一直显示 v0.1.0 的文字。

## 更新与验收

先另存文件，在原远程源检查更新并安装，再重启 Blender；不要再添加第二份插件。

```text
https://architectureworld.github.io/blender-designerBIM/index.json
```

用新示例：复制 D01 到 X=3000 → D04 相对移动 +200 → 改高2400 → 切右铰 → 添加说明后移动 -100 → 保存重开 → 统一改框80。源门和每樘门的独立尺寸应保留，相关说明需要复核。尝试移到 X=4500 应被拒绝且原数据不变。

## 验证说明

完整纯 Python／静态／打包回归运行在 CI。独立 Blender 5.2.2 runtime 工作流运行官方包验证、原 P01 和本轮操作器/真实网格/迁移/保存重开测试，结果见对应 Actions 日志与 artifacts。不能以测试脚本的存在代替运行证据。

Windows GUI 的鼠标、对话框、撤销和三视图视觉仍需人工验收。本版不包含风管、IFC 接入、完整组件库或 Agent。

旧项目写入 schema 2 后，旧插件不能继续编辑；请保留原 .blend 备份。`dbim_p01_schema1_backup` 只备份原型 JSON，不替代文件备份。
