# DesignerBIM P01 v0.1.1 — remote distribution candidate

**Target: Blender 5.2.2. Status: prerelease for local acceptance, NOT production-accepted.**

This is a packaging and distribution update to the previously delivered v0.1.0 door lab; it does not claim additional BIM functionality.

## Blender remote repository

Add this JSON URL under Edit > Preferences > Get Extensions > Repositories > Add Remote Repository:

https://raw.githubusercontent.com/ArchitectureWorld/blender-designerBIM/main/extensions/index.json

Allow online access, refresh and install **DesignerBIM P01 — Door Lab**. This URL is the repository source; the GitHub project homepage and a ZIP URL are not substitutes.

## Existing disk installation

Save a backup .blend, disable the old local DesignerBIM P01 extension, restart Blender, then install/enable the remote copy. Do not enable both copies simultaneously. Do not delete the whole Local Repository or other extensions. The state key remains `dbim_p01_state`; continued editing of existing .blend files still needs real Blender verification.

D01 opening 900→1200; modify shared frame section without resetting widths; add a D02 note; modify D02 while preserving its note and marking REVIEW; save/reopen and continue editing.
