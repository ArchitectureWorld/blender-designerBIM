# DesignerBIM P01 v0.3.1 — 统一 GitHub Pages 发布入口

**目标 Blender 5.2.2，测试候选版。** 这是 v0.3.0 门组件原型的分发维护版本，不变更功能、工程 JSON 模式或扩展 ID `designer_bim_p01`。

## 变更

- 唯一 Blender 远程扩展仓库：https://architectureworld.github.io/blender-designerBIM/index.json
- GitHub Pages 同域名托管安装包，保留扩展包的 SHA-256 与文件大小校验。
- 统一为 `.github/workflows/publish.yml` 测试、建立不可变 Release、部署 Pages 与公开访问校验。
- 删除旧的源码内静态索引文件及冗余 Pages 工作流；更新 README、快速开始、发布说明和验证脚本。
- 已发布的 v0.3.0 Release 保持不变；本次以新版本发布，不篡改既有归档校验值。

## 安装与迁移

备份 `.blend` 文件，Blender 5.2.2 中修改原远程扩展库的 URL；若无法修改，则移除旧仓库（**不删除已安装扩展文件**），再通过新地址添加一份远程库。不要同时注册两个同 ID 的 DesignerBIM 远程库。刷新后安装 / 更新至 0.3.1。

> 注意：发布要求仓库 Settings → Pages → Source = GitHub Actions，并确认 Actions 部署及公开索引/ZIP 校验成功后才可使用新链接。

## 验收界限

静态构建、索引与下载校验不等于 Blender 5.2.2 GUI/runtime 实机验收。v0.3.0 的门组件功能及限制继续以 `docs/releases/v0.3.0.md` 为准。
