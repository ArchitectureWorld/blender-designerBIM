# DesignerBIM P01 v0.3.0 — 整门组件封装

Blender **5.2.2**，测试候选版。更新源和扩展 ID 不变。

## 修复本次反馈

- 三维的一樘门只有一个集合实例操作入口。门框和门扇保留为私有集合内的独立部件，默认不平铺到项目对象列表。
- 平面、立面各以一个同身份的表达代理呈现，尺寸与符号仍由同一工程参数产生，不是三樘不同的工程构件。
- `进入组件内部 / Tab` 后才能选择门框、门扇；支持门框截面、门扇厚度的参数编辑。明确区分当前实例覆盖与共享定义；可恢复继承。
- 不焊接几何、不偷偷建立新定义。局部覆盖后，门仍保留共享 definition_id；复制继承局部参数，不复制说明和审批。
- 整门删除会清理其三维、二维表达并回填墙洞。有关联人工说明时必须确认；其他门与说明保持不变。最后一樘门删除后仍可新增。
- 3D View 组件上下文：G 打开沿墙定位，Shift+D 打开复制，X/Delete 打开整门删除确认；普通非组件对象的快捷键不被替换。
- schema1/2→3 迁移及原始 JSON 备份；旧的散件场景在载入/刷新时封装，说明与复核状态保留。
- 检测到未支持的任意内部网格修改时拒绝刷新，不静默覆盖。

## 测试方法

先另存旧 .blend 备份，原远程库检查更新至0.3.0并重启，不要添加第二份。

1. 创建测试场景，单击门框/门扇：只选中整樘门；MODEL对象列表只有D01/D02/D03的整门入口。
2. Tab进入D01内部，选择门框，编辑部件参数→仅当前实例→80；D02/D03保持60。
3. 退出后进入D02，编辑门框→共享定义→70；D02/D03变70，D01保留局部80。恢复D01继承后应变70。
4. 复制门、沿墙移动、删除门；检查墙洞及平立面同步。删除含说明的门时必须确认。
5. 保存重开：默认回到整门模式；局部参数、身份、图纸关联和说明仍在。

## 明确边界

- 内部编辑当前是受控参数编辑，不是任意网格/拓扑编辑器。不要用原生菜单的Make Instances Real、Join、Apply Transform或删除内部几何绕开组件命令。
- 快捷路由覆盖3D View。Outliner原生删除/复制及Python直接修改不是受控工程命令；请使用DesignerBIM组件按钮或3D View快捷键。
- 仍是单一直墙、门专用二维表达、JSON权威状态原型；不代表通用组件库契约或IFC生产系统已完成。
- schema3旧文件不能交给旧插件继续编辑，请保留完整.blend备份。JSON备份不是完整.blend替代品。
- 验证以对应Actions中的真实Blender集成/GUI结果为准；Windows本机鼠标和完整三视图体验仍需用户验收。
