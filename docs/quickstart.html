01 · 安装后直接做什么

1使用 Blender 5.2.2先保存已有工作。本次不用修改其他插件或项目。
2从磁盘安装 ZIP偏好设置 → 插件／获取扩展 → 右上菜单 → Install from Disk。选择 designer_bim_p01-0.1.1-blender5.2.2.zip，不要解压，也不要选源码包。
3创建原型场景启用 DesignerBIM P01；三维视图按 N → DesignerBIM → 创建原型场景。新建一面墙与三樘门，保留已有场景。
4打开三视图点击“三视图排布”，确认调整当前工作区。预期左三维、右上立面、右下平面。也可单独切换当前视图。

安装使用本地 ZIP，不需要新增远程仓库或填写 URL。官方从磁盘安装说明见页末。

02 · 五步验收

完成你来操作应该看到
选 D01，宽度 900 → 1200；只改当前实例。三维、平面、立面尺寸同步；另外两樘保持 900；门框截面不被拉胖。
统一门框截面 60 → 80。三樘门框变化；各自门洞宽度仍是 1200、900、900。
选 D02，在立面添加人工收口说明。说明出现，可在原位编辑文字、G 移动；关联 D02。
把 D02 门宽改为 1100。人工文字和位置保留；显示“需复核”。人工确认后才清除。
保存 .blend，关闭重开，再改 D03。实例关联、尺寸、人工说明和复核状态仍在，且能继续修改。

补测：拖动门右侧蓝色箭头，默认 10mm 步进；Shift 为 1mm；Esc／右键取消；完成后 Ctrl+Z 撤销。拖动保持门中心不动，仅影响当前实例。

勾选仅用于当前页面人工记录，刷新后不保存。请勿用尚未验收的原型编辑生产模型。
