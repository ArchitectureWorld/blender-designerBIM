# P01 v0.3.0 — 组件封装

用户已批准：整门操作＋进入组件内部编辑，执行并发布。范围不扩展到风管、IFC、通用族库。

- 一个门一个工程实例；MODEL中只有一个可选的集合实例入口，内部几何不再平铺到场景。
- PLAN、ELEVATION是同一实例的表示代理，独立说明仍保持可编辑和同一door_id。
- 内部几何留在私有集合中；只在显式进入当前组件时开放。默认只编辑参数，禁止悄悄覆盖任意网格修改。
- 部件支持门框截面、门扇厚度；当前实例覆盖与共享定义编辑分开。覆盖可恢复继承，不拆断definition_id。
- 复制/沿墙定位继续使用参数化命令；添加整门删除（有关联说明时明确确认）。Tab进入/退出，G、Shift+D、X/Delete在组件上下文路由到相应命令；不影响普通模型。
- 旧schema 1/2迁移到3，保留原始JSON备份、说明/复核状态；不把原型schema声明为最终族库协议。
- Blender基线5.2.2；扩展ID、远程源不变；版本0.3.0测试版；不覆盖已有release字节。

验收：整门点击/对象列表、进入选中部件、局部和共享修改、复制/移动/删除图模同步、空墙重新加门、保存重开、重复刷新无孤儿或重复物、错误操作不丢数据。Windows手工体验不冒充后台验证。
